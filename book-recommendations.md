# Book Recommendations — Agent Notes

**This file holds the rules. It holds nothing per-title.** Compact facts with
evidence, not narrative — full score history lives in [books-read.md](books-read.md).
Every bullet must trace to a specific book and score.

Four things run on these rules, and each owns exactly one kind of write:

| | Owns | Invalidated by |
|---|---|---|
| `/book-log` | scores in `books-read.md`, the rules here, and **every recomputation** of a prediction | a rule here moving |
| `/book-screen` | discovery, in two tiers: `book-triage.jsonl` (every record pulled, machine class, rough band) and then `book-cache.json` access facts, `book-rejects.jsonl`, `book-media.json`, **first** predictions for what it promotes | time passing |
| `/book-suggest` | the Snoozed list below, and nothing else | — |
| `index.html` | nothing — read-only viewer (`./serve.ps1`) | — |

**Three tiers, and only the last is an opinion worth quoting.** Between the two below
sits [book-ai-rank.jsonl](book-ai-rank.jsonl): a persisted 1-5 plausibility score per work
from a cheap model, keyed to a hash of `tools/ai-rank-prompt.md` so it is computed once and
never recomputed until that prompt changes. It answers "is this worth twenty minutes", not
"would he like it". A `3` there means *the model did not recognise the book* — never read it
as a negative.

**Two tiers, and only one of them is an opinion.** [book-triage.jsonl](book-triage.jsonl)
holds a row for every record ever pulled from the catalogue with a machine class and a
rough band — `conf: auto`, meaning a regex looked at the title, author and publisher and
nothing else. A band there is **not** a prediction and must never be quoted as one; a
`drop` there is *not pursued, revisit on request*, never a reject. Titles that clear the
promotion gate get the expensive treatment and appear in the three files below. This exists
because a sweep once pulled 16,687 records, recorded 67, and lost the rest.

Predictions live in [book-estimates.jsonl](book-estimates.jsonl) with the
dependencies each was derived under, counted in [book-revs.json](book-revs.json).
Changing a rule below therefore has a mechanical consequence: `/book-log` bumps
that rule's counter, greps the estimates for it, and rescores exactly the subset
that named it. So **rewording a rule is a real action, not a note** — and a rule
nothing depends on is a rule that will never be applied.

**A prediction is anchored to read books and to the rules here — never to another
candidate** (2026-08-26). Candidates do not mention each other: an estimate
calibrated against another estimate is a guess anchored to a guess, and both move
together when either turns out wrong. Every `why` therefore argues from scores in
[books-read.md](books-read.md) and from the axes below, in its own words, even
where that means two volumes by one author repeating the same reasoning. Sequence
and edition notes — read volume 1 first, this story also sits inside that
collection — are *facts*, so they belong in `book-cache.json` as `flags`, where
naming a sibling title is correct. Enforced by `python tools/crossrefs.py`, which
came out of 22 lines derived the other way, one of them arguing from "451 read"
when *Fahrenheit 451* is itself an unread candidate.

**This file must not grow with the log.** The log is heading past 100 books, so
evidence cites the two or three *strongest* exemplars for an axis — ideally a
controlled pair, same author or series — never every book that touches it. When
adding a book would turn a citation into a list, replace a weaker one instead.

## Scoring
Ratings are a **score out of 100**; the letter is only the band it falls in.
95-100 S+ almost perfect · 85-95 S enjoyed very much · 75-85 A nice read · 65-75 B ok · 50-65 C disliked · <50 F actively disliked. On a boundary the higher band wins.

**An absolute rating, not a ranking — any number of books may share a score** (2026-08-22). Equal scores mean equal liking. Row order among ties is arbitrary: never read a preference out of it, never nudge a score to avoid a collision, never offer to break a tie.

**A score is peak minus pushbacks, not an average.** A modest book with no downsides ties an ambitious one with several. Evidence: *The Hobbit* 84 ("nothing great, but no downsides") = *LOTR* 84 ("much greater ideas, but more pushbacks") — a deliberate tie, not unfinished business. So don't assume the ambitious pick is the better bet.

**The A and B bands are acceptable outcomes, not failures** — don't optimise only for the top. An occasional high-60s read to expand horizons is explicitly welcome. Only sub-65 is a thing to avoid.

## Filters

**Only five bars are absolute:** no readable route, an unclear opening, real-world occult on the page, detective/mystery, and infidelity as the premise of the book. Everything else is graded — flag it and let the reader decide, never silently exclude.

**A hard exclusion is inherited by any sequel that depends on the excluded book** (reader's rule, 2026-08-31: "if the book is hard excluded, also the sequels should"). **The unit is DEPENDENCY, not the series** — and that distinction is not pedantry, it is forced by the evidence: *Mort* 83 is volume four of a series whose volume one was abandoned at 30, and it is the best result this author has in the log, so "same series" cannot be the test or the rule would have excluded it. The test is one question: **can this book be read without the excluded one?** If the plot continues it, or the lead or premise is introduced there and assumed rather than re-established, the exclusion carries and the book is `blocked`, not given a low range — a range says *unlikely*, and these are *unreachable*. If the book restarts with its own lead and premise, it does not inherit. **An `access` reject does not propagate as an exclusion** — it is a dated fact, so the sequel stays live with a note that its route is missing. The links live in `book-cache.json` as `prereq` (added the same day, because until then reading order existed only as prose and nothing could join on it); `need: hard` is what triggers inheritance. **First application removed 13 books from the queue**, and only four of them were the author this came up about — see Open questions for what the sweep could and could not see.

**Clearing a filter is not a reason to propose** (2026-08-26). The four bars are exclusions, not endorsements: "short, in Czech, no occult" describes a book that has merely failed to disqualify itself. Every proposal needs a *positive* case on the graded axes — ideas, protagonist, motives, worldbuilding — stated in its own words. An estimate whose `why` is a list of filters passed is not an estimate.

**Severity among the graded objections** (from the ranked disliked band, 2026-08-19, revised 2026-08-22): occult ≫ crude sexual content > incoherent premise > flat or unrootable protagonist > prophecy handling > bleakness (mild; only *1984* 60 ever triggered it). Two adjustments to that score-derived order when *proposing*: incoherent premise is one of only two objections known to end a book unfinished in the first chapters (*Mortal Engines* 55), so weight it above its rank; and violence and swearing are not objections at all within limits.

- **Hard — readable in Czech, *or* free to listen to in English.** Reads in Czech; English *text* breaks immersion. A free English **audiobook** is fine — LibriVox, the library's eKnihy/eAudio, YouTube. Evidence: stated 2026-08-19.
- **Hard — no confusing/unclear opening. Still *confusion*, not slowness — but confusion has two shapes, and the second was added 2026-08-28.** **Shape one — too many threads:** several plot lines starting at once before any is legible. Evidence: *Guards! Guards!* 30 (abandoned p. 15, ~6 threads at once), *The Colour of Magic* 30. **Shape two — no context for the thread you get:** dropped into an action already underway, followable sentence by sentence and meaning nothing, because who these people are, what the invented terms denote and why any of it matters have not been established. Evidence: *Čaropisci* 30, DNF in chapter one — a heist already running, with scriving, sigils and four merchant houses arriving unexplained; the reader's own words were "starts from nowhere, with nothing immersing me", and on being shown what the chapter actually contains he placed it as "lots happening, none of it meant anything yet". *The Gunslinger* 30 is the same shape. **What kills is missing context, not missing incident.** An action opening is therefore no defence, and **"the first chapter has a heist in it" is precisely the argument that failed here** — the *Čaropisci* estimate leaned on momentum and a rootable thief and lost 46 points. **A legible-but-uneventful opening is NOT this filter**: that reading of *Čaropisci* was put to the reader and rejected, and *The Silmarillion* 80 is quiet, archaic and cold and scored fine. What he wants is one concrete starting situation **he has the context to read**, and to be invested immediately. **An early DNF does not by itself diagnose this filter** — *Mortal Engines* 55 was dropped in the first chapters on premise logic with no complaint about clarity (2026-08-22). Two objections end a book that early — this filter and premise logic; ask which.
- **Hard — no occult, in any setting.** Two tests, and **failing either one is a veto** (ruled 2026-08-26 — see the next bullet, which is why this needed a ruling). *Source:* a system drawn from actual occultism fails — witchcraft, spellcasting in that mould, séance, divination, necromancy, sacrifice or prayer to real deities; an invented system passes this test. *Depiction:* **a rite enacted on the page fails even when the system is invented**; a practice mentioned as having happened is fine. **The escape is mechanism** — a system operated like technology or engineering, with declared rules and no invocation, devotion or priesthood, passes Depiction even when used on the page: Allomancy, Bennett's Founders scriving, Asimov's mentalics, salvaged "elf-magic" that is really pre-collapse tech. **But resemblance still vetoes:** "if it's mechanical it could be plausible explanation to keep it normal, but if too similar to occult it should be still vetoed." So the operative question is **not** whether the system is invented but **whether a rite is performed on the page and whether there is a genuinely mechanical account of it.** Evidence: *Harry Potter* 51, *The Witcher* 53, *Percy Jackson* 57 — three of the four lowest completed scores, with *Ready Player One* 55 interleaved; and *Havran* 40, where the reader named occult as the second of two causes — the narrator questioning the bird about the dead Lenore is divination in the historical-occult mould. Note *Havran* was read and scored rather than dropped: the filter governs what gets **suggested**, not what he is capable of finishing. Passing cases: *LOTR* 84 (wizards, no real-occult analogue), Narnia 67 (a witch, but no ritual practice). Consequence: invented *mechanical* systems are eligible and were previously screened out in error — but invented *ritual* systems are not.

- **Why that ruling was needed, and what it cost (2026-08-26).** This file contained two worked rulings that contradicted each other on exactly one cell — an invented system whose rites are enacted. Bennett's *Divine Cities* was dropped because "the divinities are invented so the occult *source* test passes, but miracles function as rituals learned and performed on the page, which fails the *depiction* test — the hard filter". *Jonathan Strange* was passed because "the raising and the faerie bargain are an invented system in an alternate England". Both dated the same day. A promotion agent hit the cell on six Daniel Abraham novels, could not resolve it from these notes, and correctly flagged it rather than guessing. **The ruling makes *Divine Cities* right and the *Jonathan Strange* row wrong** — see that row, now corrected. The general lesson: a filter stated as two tests must say whether it is AND or OR, because the ambiguity is invisible until a book lands in the gap.
- **Hard — no detective/mystery novels.** Deliberately avoided, so few have been read; the absence of data is self-selection, not a gap (2026-08-19). Watch for *investigation-shaped subplots* in eligible books too — flag rather than drop (e.g. *Leviathan Wakes*, half of which is a missing-person case).
- **Hard — infidelity as the premise of the book (ruled 2026-08-27).** **Scope is marriage or engagement only**: a betrayal between unmarried partners is ordinary relationship drama and does not touch this axis. **Premise level is always a reject, whatever the framing** — "when the premise of the book is infidelity then reject it always". Premise means *remove the infidelity and there is no book*: the main plot, the central relationship, or the engine of the conflict. So *Anna Karenina*, *Madame Bovary* and *Effi Briest* are **rejects, not low scores** — ruining the adulterer is not a defence, because the reader is still being asked to spend a novel inside the affair. **Literary reputation earns nothing here**, consistent with "clearing the filters is not a reason to score well". This superseded a first draft the same day that made the veto conditional on the affair being *celebrated and unpunished*, and it is the simpler rule as well as the stricter one: framing no longer enters the veto at all, so the test is prominence alone and a blurb usually settles it (budget 2, not 3, and the ending need not be established). Where premise vs subplot is genuinely unclear, grade it as a subplot and say so — a wrong reject is unrecoverable.
- **Infidelity below premise level — graded on two dimensions that multiply, each severe alone.** *Prominence* (incidental / subplot) against *framing* (condemned or destructive / neutral / approving — celebrated, presented as liberation, or simply unpunished): an approving incidental moment lands in the 50s, a neutral subplot 45-55, an approving subplot 30-40. **Two open items:** no book in `books-read.md` anchors this axis — 49 scored books and not one note mentions infidelity — so these bands are the reader's stated intent rather than derived from a real score; and the 270 estimates already recorded were never screened for it. Note also that this axis grades on *amount* while the sexual-content axis below deliberately does not; that difference is intentional.
- **Sex as the plot is a HARD FILTER, added 2026-08-27** — in the reader's words, reject "when the plot is severely/mainly about sexual behavior/relationship". This is the first time prominence vetoes on this axis, and it is deliberately narrow: the test is what the book is *for*, not how explicit it is. **Remove the sex and there is no book** — the same premise test the infidelity filter uses, and it is not a marriage rule. A relationship novel where the sex is one thread among the characters' lives stays graded; a book whose *theme* is desire or sexuality while its plot is about something else stays graded. Tasteful handling is no defence at premise level, exactly as condemning the affair is no defence under the infidelity filter. **Filter id is `axis:sexual-content`** — `axis:sexual-treatment` remains the graded crudeness axis below it, and the two must not be merged: one asks how much of the book this is, the other asks how it is handled. **Scope note, stated honestly:** no book in `books-read.md` anchors this filter — every sexual objection in the log sits on a book whose plot is about something else, so the bands here are the reader's stated intent, not derived from a real score. **Corrected 2026-08-28:** *Artemis* 69 and *Ready Player One* 55 are crudeness deductions and can be quoted; *Válka starého muže* 87 and *Red Rising* 95 are both low-volume rows that test nothing; and *The Witcher* 53 is confounded with the occult filter and cannot be quoted at all — see the crudeness axis below. The 412 estimates on file were computed without this filter; 75 examined a sexual axis and were re-checked on 2026-08-27, and all 350 carrying this dep were re-stamped on 2026-08-28 (`axis:sexual-content` rev 3).
- **Sexual content — volume, explicitness and crudeness ALL cost and compound** (established 2026-08-27 by the reader: "depending on the volume, explicitness, crudeness all bring it down. The Red Rising has not big volumen/expliciteness/crudeness"). **Crudeness is the only dimension the log actually anchors. Volume is real but UNMEASURED — do not price it as cheap or as fatal.**

  **What the read books do and do not establish** (all three clarifications volunteered by the reader on 2026-08-28, after two estimates-wide passes had been built on the wrong reading of them):
  - ***Ready Player One* 55 — the one clean crudeness anchor.** "It was the kind of sex that reduced it that much": the *kind*, not the amount, and no second filter fires on this row.
  - ***Artemis* 69 — crudeness confirmed at the low end of volume.** Crude in small doses and docked anyway, a deduction separate from its protagonist.
  - ***Red Rising* 95 and *Válka starého muže* 87 — both LOW volume, so neither tests it.** "In Red rising the volume is not big"; in VSM "the volume is not that big, it's mostly one chapter of a book". What VSM *does* show is the opposite of a free pass: **one chapter was enough to become his single named complaint on a book he otherwise praised throughout.** Light volume registers.
  - ***The Witcher* 53 — CONFOUNDED, never cite it as a sexual-axis floor.** "There was both magic (witches) and the sex was through out the series." The magic is the **occult** filter, the most severe objection in the log, so most of that 53 belongs to a different axis. It is also the log's only high-volume row, and it is unusable — which is exactly why volume has no anchor. It had been quoted as a single-axis floor in **25 estimates**, all corrected 2026-08-28. Where a book needs a severity comparator here, use *Ready Player One* 55.

  **Consequence for estimates: state which dimension carries the deduction, and never let volume carry one alone.** A high-volume, non-crude book is genuinely unpredictable on this axis — say so and widen the range rather than picking a side. **"Only occasional" remains mitigation, not clearance**: low volume reduces the deduction but never rescues crude treatment, and VSM 87 shows it does not reduce it to nothing. **The axis is sexual references specifically, not the vulgar register** (resolved 2026-08-22: in *Artemis* "the problem was the sexual references, not language"). A coarse, profane or juvenile *voice* is not itself an objection — that stays inside the violence-and-swearing tolerance. Judge what the book is crude *about*.
- **Genre is otherwise open.** The SF/fantasy skew is a sampling artefact. Evidence: historical fiction (*Exodus* 68, *Quo Vadis* 66), memoir (*Seeking Allah* 91, *Son of Hamas* 75), allegory (*Animal Farm* 78, *The Little Prince* 82) — all read, none disliked.

## The heaviest axis — does it hold up under thought?

Unifies the profile across genres. Three faces, each with its own evidence: *premise* — consequences worked out and reveals set up (*PHM* 92, astrophage's consequences followed through; *Golden Son* 92, the Fitchner-as-Ares reveal earned rather than sprung); *structure* — the parts connect to each other (the Tolkien gradient *Hobbit* 84 / *LOTR* 84 / *Silmarillion* 80 / *Unfinished Tales* 69 "fragmented and not aligned", mirrored by *Hitchhiker's* 83 vs its shapeless sequels 70); *fact* — real-world claims must be true (*Seeking Allah* 91, which weighs what is believable; *Ranger's Apprentice* 74, false historical claims stated as fact).

**The one principle: the author must follow the rules he lays down** (the reader's formulation, 2026-08-22). Self-consistency with declared commitments, *not* an external realism audit. Nothing obliges an author to explain anything — but whatever he asserts, foregrounds or undertakes to explain becomes binding. Five forms, one breach:

1. **Declare a capability → the world must carry its consequences.** FTL or magic means the society is visibly different for it — *"then there would be colonization, the society would change"*.
2. **Undertake to explain → the explanation must hold.** Choosing to explain creates the obligation; silence would not have.
3. **Take a society as your subject → it must cohere.** *Divergent* 58 — the factions and genes *are* the subject.
4. **Declare a resource scarce or sacred → it must behave that way.** Invented resources are therefore *not* free.
5. **Declare a trait in a character → it must be shown.** *Divergent*'s Erudite are billed as intelligent and never written so. Same rule, not a separate axis (2026-08-22).

**What is actually binding — four scoping rules:**

- **Where nothing is declared, reality binds — set by the tech level the book *presents*, not the date it is set in.** *Mortal Engines* 55 "starts in the real world in the future, but... the science did not go much further, so the real world logic should still apply"; escape needs *"some indication that now is something different"*. This is the asymmetry with *Ender's Game* 87, which reads genuinely advanced and gets its battle station free.
- **Jurisdiction is per world, and cross-world duty scales with the traffic — which has a direction.** *"Real world needs to be bound by real world rules... The magic world has it's own rules."* Check each direction separately and ask whether the declared mechanism covers *that* direction. **Narnia 67** owes nothing either way — a wardrobe now and then is negligible. **Harry Potter 51** is fine outbound, because secrecy is a declared, enforced institution that *earns* magic's absence from mundane life — the principle working in an author's favour — but breaches inbound: *"there are muggles accepted to the school of magic"*, arriving yearly with modern knowledge that wizarding society absorbs none of. Secrecy seals outbound influence; it cannot seal what immigrants bring in. **Generalisation:** for hidden-world and portal fiction, find who crosses over and stays, and ask what they bring.
- **The obligation scales with how precisely the thing is declared — the author sets his own bar** (hedged "i think"). Narnia's magic is "not declared as something very understandable and logical, so it's not that big of a problem"; Tolkien's unsystematised magic likewise costs nothing. This does **not** conflict with "consequences, not rules": rules add *obligation*, not bonus. Sanderson passes by meeting the bar he set, not by setting one.
- **Exemption follows how hard the book *leans* on the thing, not what it is nominally about.** *Harry Potter* 51 is a school story and still takes a worldbuilding hit, because magic is the medium of every scene. *Hunger Games* 89 merely mentions Panem's economics; *Ender's Game* 87 uses its station as a place events happen in. Lean, not aboutness — so don't grant the exemption just because a book is character-led.

**Scope in time: an answer anywhere in the book counts.** *"If it's explained further in the book it's ok."* So "explained later" is a valid defence — but verify it, because **the reader verifies**: he searched online before abandoning *Mortal Engines*. A sequel does not count.

**Weight:**
- **Graded, never a bar.** The deduction tracks how *central* the breach is and how *badly wrong*, together — neither alone predicts anything, and physical and social implausibility weigh the same.
- **It adds points, but a flat protagonist outranks it** (settled by *Artemis* 69, whose world-logic was explicitly fine and which still landed 23 under *Project Hail Mary* 92 — revised down from 76 on 2026-08-27 for the same two reasons, which widens the gap and makes this the strongest single case in the log). **Never predict a book up on worldbuilding when the lead looks thin.** Same shape against story density (Tolkien, good world, capped at 84) and in the Ender sequels (better world than *Ender's Game* 87, yet #3-5 at 81).
- **It can end a book by itself in the first chapters** — one of only two DNF causes, needing no supporting fault.
- **Positively confirmed, not only inferred from failures** (volunteered 2026-08-22): *Hunger Games* ("thought through and makes sense"), *Ender's Game* ("very good"), both Weir novels ("awesome"), *Red Rising* and Tolkien all named as good worldbuilding — five authors, 84 to 95. **Six now, and the sixth states the premise face as a positive rather than a defect** (*Válka starého muže* 87, volunteered 2026-08-28): "there weren't much of the characters just having luck and the author saving the plot when it was useful," alongside a world that stays consistent through three shifts of perspective. **Authorial rescue is the same breach as a sprung reveal** — the author declaring stakes and then not honouring them — so it is this axis, not a separate one, and it is now the only face with evidence from both directions: *Golden Son* 92 for the reveal earned, this for the rescue refused. Failures: *Divergent* 58, *Mortal Engines* 55, *Harry Potter* 51, *Ranger's Apprentice* 74 (false historical claims as fact), *Unfinished Tales* 69 and the Hitchhiker sequels 70 (structure face).

## Preferences (ordered by weight of evidence)
- **Motives over action** — page time on what characters want and why beats page time on what they do; set-piece action with no character revelation is dead weight. Four authors, all controlled and all agreeing: Collins *Mockingjay* 91 > *Hunger Games* 89 > *Catching Fire* 83 ("arena for its own sake"); Weir *PHM* 92 > *Martian* 82; Brown *Red Rising* 95 > *Golden Son* 92 (docked for leaning on action); Card *Speaker* 90 > *Ender's Game* 87 > *Shadow* 79.
- **The protagonist must be interesting *and* worth rooting for** — two failure modes, and **this beats worldbuilding when they compete**. *Not rootable:* a villain lead or a slow descent into evil, however well written — *Sunrise on the Reaping* 87 (Haymitch) vs *Ballad* 65 (Snow), same author, world and form, **22 points on the protagonist alone**. *Not interesting:* flat even when likeable and competent — *Artemis* 69. Weir is the controlled case, **92 > 82 > 76** with world-logic strong throughout, though Artemis also carries a content deduction, so not all of that gap is the lead.
- **Wants higher things to think about** — a book should leave ideas behind, not just events; the most common reason a competent book stalls in the 60s. Evidence: Narnia 67 and *Ranger's Apprentice* 74 marked down for lacking them; *Seeking Allah* 91, *The Little Prince* 82, *Animal Farm* 78 rated on their ideas.
- **Short idea-driven works have the character and emotional rules suspended — but the ideas still have to be good** (sharpened 2026-08-26; previously read as "judged on their ideas alone", which was taken as a free pass). The suspension **removes penalties, it never adds points.** Evidence for the suspension is solid: *The Little Prince* 82 (child lead), *Animal Farm* 78 (bleak), *The Silmarillion* 80 (no protagonist) each break a rule that costs other books points and none is penalised. But notice what those three share — each is canonical *for its ideas*. **The category looks safe because only its best examples have been read; that is selection bias, not a property of short fiction.** So there is no ceiling boost for being short, and a short book with thin ideas lands in the 60s like any other thin book. **Name the idea when proposing one — if you can't say what it is in a sentence, that is the finding**, and "it's short, so it's low risk" is not a case for reading it.
- **Unearned competence is a turn-off** — ability and status *given* rather than earned; effortlessly good at everything. Evidence: *Divergent* 58 (Tris). Distinct from the messianic objection below, with which it was wrongly merged until 2026-08-22.
- **Prophecy and chosen-one plots are a graded deduction, never a filter** (corrected 2026-08-22; they had been treated as near-disqualifying and a candidate was withheld on that basis in error). **"Some prophecy about a saviour is ok"** — the deduction scales with how *present* it is and how hard it is *leaned into*. **The axis is reverence, not resemblance:** Aslan is the closest Christ figure fiction has and is *not* among Narnia 67's objections — "reverent allegory is fine". What costs is careless handling — Jesus resonance a book hasn't earned — or a treatment played for ridicule. **Subversion is judged on tone:** a manufactured saviour played seriously is fine, played for cynicism is not. *Dune* was declined partly on prominence. Consequence: **stop screening out epic fantasy for having a prophecy**, and don't flag a Christ parallel merely for existing.
- **Verse does not work, whatever it is about — a new axis (2026-08-27).** *Havran* 40 ties the lowest completed score in the log, and the reader named the form itself as the first of two causes. This is distinct from the short-idea-driven suspension: a short *prose* work merely fails to earn points, while verse carries a penalty of its own. The catalogue holds a great deal of poetry and nothing screened for it before this. Evidence: *Havran* 40.
- **Story density is the penalty term, not length** (corrected 2026-08-19). What costs is a thin story spread over many pages. *The Hobbit* 84 = *LOTR* 84 because LOTR's far greater ideas are cancelled by how sparse its story is for its length — length itself was explicitly *not* the objection. Consistent with *Monte Cristo* 75 and *Les Misérables* 71, both docked for digression. **Never discount a candidate for being long**; discount padding — description, digression, drawn-out endings (*The Martian* 82). A long, densely plotted book carries no penalty.
- **Sustained bleak emotional states are disliked, but mildly** — isolation, hopelessness, unrelieved grimness. The *least* severe recorded objection and a rare one: *1984* 60 is the only book grim enough to matter, and is the highest score in the disliked band. A discount, not a bar. Companionship and self-sacrifice beat solo survival: *The Martian* 82 (docked partly for loneliness) vs *PHM* 92 (Rocky, sacrifice plot) and *LOTR* 84 (heroism, friendship).
- **Faith and religion as a thread inside a story**, not as the whole of it — no theology or apologetics as a subject in its own right. Evidence: *Seeking Allah* 91 and *Son of Hamas* 75 carry faith inside a narrative; stated directly that a theology book is not wanted.
- **The memoir/testimony form earns nothing by itself.** What earns is the examination of what is true plus insight into how another group experiences the world. *The Diary of a Young Girl* 40 (DNF) is the same form as *Seeking Allah* 91 and failed outright.
- **How much of a children's book it is — graded, never a filter** (ruled 2026-08-26: "children should not be a hard limit, it was just not to do screening from children books. The score depends how much children book it is"). The exclusion belongs to the **triage sweep**, which keeps the children's section out of the queue in the first place — `tools/ai-rank-prompt.md` still scores children's and early-reader rows a 1, and that is correct. But once a book is under consideration it gets a number: *Hobbit* 84 and *The Little Prince* 82 pay nothing, *Ranger's Apprentice* 74 and Narnia 67 pay a little, and a picture book lands in the 30s or 40s. Two promotion agents hit this independently on 2026-08-26 — one declined to reject two middle-grade volumes because there was no `axis:childrens` id to spend, the other had to file a genuine picture book under `axis:life-phase` — which is what surfaced the question. `axis:childrens` now exists and is **the book's register and audience**, distinct from the life-phase pushback below, which is only the lead's age. A book can have a child lead in a wholly adult register, or an adult lead in a nursery one.

  **Screened deliberately on 2026-08-27, on the reader's request, and the axis behaves as stated.** The whole 6,779-record *literatura pro děti a mládež* heading was enumerated and the crossover seam promoted: 30 titles now carry estimates spanning **52 to 86**, which is a wider spread than any other single screen has produced, and the register deduction is what orders the bottom of it. Three findings worth keeping. **First, the deduction is not a constant — it scales with whether there is an adult layer for it to grade.** *Nekonečný příběh* and *Momo* pay almost nothing at 78-86 because what they are about is not childlike; *Medvídek Pú* pays heavily at 60-70 because the excellent jokes sit on nothing declared and nothing at stake; the age-banded serials that fill the shelf pay everything, which is why they are a category reject rather than a graded row. **Second, this category is the one place where a heading sweep is not sufficient on its own** — the library files the best of the crossover canon as adult prose, so *Nekonečný příběh*, *Momo*, *Sofiin svět*, *Alenka*, *Zlodějka knih*, *Robinson Crusoe* and *Huckleberry Finn* are all absent from the children's heading and were recovered only by name afterwards. **Third, the occult filter fires far more often here than anywhere else** — four title-level rejects in one pass, because a witch or a sorcerer's apprenticeship is a stock children's premise.

- **Protagonist life-phase proximity — a small pushback only** (reader is 28, 2026-08). Worth a couple of points, never a tier, and never a reason to reject. What counts is how the inner life reads, not the stated age: *Ender's Game* 87 marked down slightly because Ender *feels* like a child from the inside. No penalty for 16-year-olds who don't read as teenagers (*Red Rising* 95, *Hunger Games* 89), older leads (*LOTR* 84), or short allegory (*The Little Prince* 82).
- **Multi-POV openings are fine when the threads are staggered — the failure is simultaneity, not multiplicity** (sharpened 2026-08-19). A new line every few pages, or one per chapter, is welcome. Evidence: *Guards! Guards!* 30 (~6 threads by p. 15, all at once) vs *LOTR* 84 and *Golden Son* 92, each thread anchored before the next arrives.
- **Each character needs its own motives and way of thinking** (Darrow ≠ Sevro ≠ Mustang) — differentiation, explicitly *not* cast size. A larger cast is not itself a draw. Evidence: *Golden Son* 92.
- **Sequels are not safe bets** — a strong book 1 does not transfer. *Hitchhiker's* 83 → 70 (−13, steepest in the log); but Collins reverses it, *Catching Fire* 83 → *Mockingjay* 91. Score each entry. **Reworded 2026-08-31 to carry the inheritance rule** in Filters above: this axis now decides exclusions as well as scores, so a sequel needs a `prereq` verdict before it needs a number. The two directions are independent — a weak book 1 does not exclude book 2, only an *excluded* book 1 does, and a strong book 1 still buys book 2 nothing.
- **Fast start and constant momentum.** Evidence: *Red Rising* 95, *Hunger Games* 89, *Ender's Game* 87.

## Open questions
- **RESOLVED, and the other way round from how it was first written (2026-08-28). The axis a prediction *doesn't* examine is the one that kills it — neither direction is the safe one.** This used to read "predictions built on prose, pacing or opening structure are weaker than predictions built on plausibility", on the single case of *Mortal Engines* 55: argued on its opening, lost on the world logic the prediction never looked at. *Čaropisci* 30 is that case exactly inverted — argued on worldbuilding and a rootable lead, lost on the opening, which the prediction never looked at either. Two reads, opposite leans, same shape of miss, so there is no weaker axis and no stronger one. **The operative rule: every estimate must state a verdict on both the opening and the world, and say which one it is leaning on.** (The Scalzi / Crouch / Taylor re-audit the old wording called for was **done 2026-08-22** — results are in their Author rows.)
- **A second prediction failure, different cause:** *Artemis* was predicted 80, scored **69** (revised down from 76 on 2026-08-27), because the prediction leaned *up* on strong worldbuilding while the lead was visibly thin — an 11-point miss, not a 4-point one. Both of those failures come from predicting on the wrong axis, not from bad information.
- **A third prediction failure, and the first caused by `risks` rather than `leanedOn`:** *Proměna* was predicted [70, 78] and scored 58 — twelve points under. The lean was right (`axis:ideas` + `axis:short-idea-driven`; the idea is real and nameable), but both cached risks fired together: `axis:protagonist` (Gregor is passive and hard to root for) and `axis:bleakness` (arriving at once rather than gradually). So the lesson is not "lean on a different axis" but **a range whose risks both fire is not a range at all** — price the downside, don't average it in. Evidence that the mechanism works: *Labyrint světa* 70 leaned on the identical pair and landed inside [66, 76] because its `axis:faith` risk did not fire.
- **A fourth prediction failure, and the first in the *upward* direction:** *Válka starého muže* was predicted **[66, 76]** and scored **87** — eleven above the top. The wrong `leanedOn` was **`axis:protagonist`**, and the specific error is nameable: the estimate reasoned "everyman narrator ⇒ the *Artemis* 69 failure mode" and pulled the whole range down a band on it. **An ordinary lead is not a flat lead.** *Artemis* fails because Jazz is not *interesting*; John Perry is deliberately unremarkable and is interesting anyway. The three earlier failures all over-predicted, so the running assumption that the risk is optimism is now wrong — a risk axis priced *without* checking whether it actually fires costs just as much in either direction. **Not yet promoted into the protagonist rule above**, because that axis is a mandatory dep on all 686 estimates and 161 lean on it; say so if it should be, and `/book-log` will bump and rescore.
- **A fifth prediction failure — the largest miss in the log, and the first where the axis that killed the book was in `deps` but not in `risks`:** *Čaropisci* was predicted **[76, 84]** and scored **30**. `leanedOn` was `axis:worldbuilding`, `risks` held only `axis:ideas`, and `axis:opening` sat in `deps` as a mandatory minimum with **not one word of the `why` addressing it** — 567 pages of heist argued on scriving and on Sancia being rootable, neither of which the reader ever reached. The lesson is not the *Artemis* one (that guard, "never predict up on worldbuilding when the lead looks thin", did not apply — the lead was fine on paper). It is that **a mandatory dep nobody argued is worse than a risk priced wrong**: an unexamined hard filter reads as cleared. Consequence, stated honestly: the 684 remaining estimates carry `axis:opening` by construction, but only 34 name it as a risk and only 15 lean on it, and of those the great majority clear the filter by arguing *one concrete situation and forward motion* — which is exactly what *Čaropisci* had. **They have not been screened for whether the reader would have the context to read that situation**, and that is a real hole, not a formality. **A second lesson about this skill, not about the book:** the first pass classified the DNF as a legible-but-cold opening on the reader's own answer, rewrote the filter around it and re-stamped every estimate — then a check of what the first chapter actually contains reversed it within the same session. **Ask what the book does before deciding what a reaction to it means**; a reader reports the experience accurately and is under no obligation to diagnose it.
- **Discworld was screened the same day it reopened, and the whole screen rests on one unverified thing: opening structure taken from outside knowledge rather than from the openings (2026-08-31).** 30 novels, 17 rows written and 13 rejected, and the axis that decided almost every placement is `axis:opening` — yet the library's annotations carry premise and protagonist and say nothing whatever about how a book starts. So the thread counts in those `why` fields ("four strands start close together", "two staggered") are assertions from memory of the books, at medium-high confidence, and they are exactly the class of claim that cost 46 points on *Čaropisci* 30. **The reader's own opening data is three points wide — 30, 30, 83 — and the 83 is the one where he does not remember the opening,** so there is nothing to calibrate against. Two consequences worth acting on: verify the first chapter before *proposing* any of these, not before recording them; and treat the four low-recorded Mrakoplaš ranges and the medium-confidence detective rejects (*Pátý elefant* especially) as the first rows to revisit if a proposal from this batch lands badly.
- **The sequel-inheritance sweep was a PROXY and it has a known blind spot (2026-08-31).** With no `prereq` links on the shelf yet, the only way to find candidates sitting behind an excluded predecessor was to join `book-rejects.jsonl` to `book-cache.json` **on the author's surname**. That produced 45 flags of which **10 were real** — the rest were surname collisions (three different Blakes; Tana French against Jonathan French; Lee Child against Preston & Child; Matthew Ward against J. R. Ward) or a reject in a *different* series by the same author (Cornwell's Sharpe is untouched by a Saxon Stories reject; Asimov's Foundation by a Robot-series one). **The blind spot is worse than the false positives:** the join can only see a series whose excluded volume happens to carry a reject row under the same surname, so a series whose volume 1 was *never screened at all* is invisible to it, and 557 of 905 cache rows carry no `series` field for it to work from. So this rule is now correct in the file and only *partially* applied on the shelf. Backfilling `prereq` across the 55 series that hold two or more candidates is the work that would close it.
- Scores drift with the reader, not just the book (*Ender's Game* was higher on first read). Old ratings may need re-confirming rather than trusting.
- *Seeking Allah, Finding Jesus* may belong at 95+ ("maybe it was even S+"); held at 91 by the reader's own choice.
- **Not gaps, and not to be tracked as such** (2026-08-22): missing *why* notes on old entries, and ties. Completeness of the reasons column is explicitly not a metric — ask about one older book only when its reason would change a conclusion being written. **Closed as unrecoverable, stop asking:** why *Ender saga #3-5* 81 sits nine under *Speaker* 90 (asked three times), and whether *Ready Player One* 55's world contributed.

## Authors

**Status is a prior on an author's *named* works, never a licence.** Established 2026-08-26 after four splits had to be made in a single day (Bennett, Čapek, Chiang, Hirsi Ali) and one false negative was found (Le Guin). Two rules:

- **Never propose a title because its author's row is `Top pick` or `Predicted fit`.** The title needs its own filter pass and its own worldbuilding verdict. Divine Cities was nearly proposed exactly this way — the author row said "Predicted fit — strong" and the book fails a hard filter.
- **Never let a title-specific objection downgrade the author.** Le Guin sat at `Downgraded` for a week over Earthsea's true-name spellcasting while *Levá ruka tmy* — society as subject, one declared premise worked out through politics, language and religion — sat unproposed on the shelf. Downgrade the work, scope the row. **Confirmed against a real score 2026-08-31, and on the objection most tempting to generalise:** Pratchett sat at `Avoid` on two DNF'd openings, with the row concluding "it's the prose style", while *Mort* 83 — same author, same series, same prose — had already been read and liked. An opening failure is title-level like every other objection, and two of them in one series is still not an author verdict.

**The real unit is the work, and the levels are author → series → volume → component.** The log's own within-author spread proves the author level is too coarse to predict with: Collins runs 91 → 65 (a 26-point spread inside one `Top pick`), Weir 92 → 76, Tolkien 84 → 69, Card 90 → 79, Adams 83 → 70. Those gaps are wider than the distance between `Top pick` and `Fine, low` as categories. Bennett needed three verdicts for three series; *Příběhy vašeho života* needed flags on two individual stories. **Every Status cell must say what it covers** — "Ender canon only", "Founders yes, Divine Cities no" — and a row without a scope is a bug, not a shorthand.

## Access-checking methods

**Search YouTube for a full reading.** Judge the titles, don't count hits — results mix full readings with summaries, abridgements and AI narration.
```
curl -sL -A "Mozilla/5.0" "https://www.youtube.com/results?search_query=<title>+<author>+full+audiobook" \
 | grep -oE '"videoId":"[^"]{11}"|"title":\{"runs":\[\{"text":"[^"]{10,140}"' \
 | sed 's/"videoId":"/ID /;s/"$//;s/.*"text":"/T /' \
 | awk '/^ID /{id=$2} /^T /{sub(/^T /,""); if(id!=""&&!seen[id]++){print id" | "$0}}' \
 | grep -iE 'audio ?book' | grep -viE 'summary|recap|review' | head -4
```

**Always duration-check before giving a link out** (learned 2026-08-19, four dead links in one pass).
```
curl -sL -A "Mozilla/5.0" "https://www.youtube.com/watch?v=<ID>" | grep -oE '"lengthSeconds":"[0-9]+"' | head -1
```
Uploads titled "Full Audiobook Free" are routinely 1-5 minute stubs — that channel style is the tell, and re-checks on 2026-08-19 and 2026-08-22 found every such hit for Mistborn, The Will of the Many, Recursion and We Are Legion still stubbed. Anything under ~60 % of published runtime is abridged or AI-compressed — say so rather than linking it plain. Full uploads are usually found instead by searching `<title> <author> audiobook part 1`, or by the narrator's name.

**Catalogue API gotcha: strip the diacritics.** A query whose first significant word carries a diacritic returns zero hits — `Tři mušketýři`, `Půl krále`, `Jurský park`, `Temná hmota` all came back empty while the books are on the shelf; `Tri musketyri`, `Pul krale`, `Jursky park`, `Temna hmota` all hit. Author surname alone also works. Never treat a diacritic query's `NO HITS` as absence.
```
curl -sL --get --data-urlencode "q=Jursky park" "https://katalog.mekvalmez.cz/api/search"
```
Read `result.content[].name` plus `responsibilityStatement.text` — that field distinguishes a translation, a comic adaptation and an audio edition. Check the *edition*: an audiobook-only publisher (Témbr, OneHotBook, Tympanum) can mean no print copy.

**The other fields worth reading, verified against a live record 2026-08-26:** `publishers[0].text` (the whole "V Praze : Odeon, 2008" string, place and year included), `publicationStartYear.value`, `isbns[0].text`, and `id` — the record UUID, which is the borrow link (`/records/<id>`). Guessing at `publisher` or `year` as flat keys returns empty strings and looks like missing data.

**Detect an audio edition on `čtou`, not only `čte`** (learned 2026-08-26). A two-narrator record reads "čtou Josef Somr a Magdalena Sidonová", and a checker matching only the singular read Hrabal's *Pábitelé* — which this library holds solely as a Popron audiobook — as a print copy. Match `čt[eo]u?`, `načet`, and the audio publishers.

**Correction 2026-08-26 — the API paginates fine; the old note had the parameter names wrong.** `page` / `size` do return HTTP 500, but **`pageNumber` and `pageSize` work**, `pageSize` up to **100** (150 and above → 500). `sorting` accepts the ids in `availableSortings`: `relevance`, `PNAZEV` (title), `REZS_AUTOR`, `REZS_ROK` (oldest first), `-REZS_ROK` (newest first). `q` supports boolean `AND` and trailing wildcards. `result.totalElements` / `totalPages` give the real hit count. So the catalogue is sweepable, not just checkable — "query narrowly instead of paginating" was a self-imposed limit, not an API one. Facet ids exist (`REZS_PREDMET` keywords, `REZS_DESKRIPTOR` genre, `REZS_AUTOR`, `REZS_JAZYK`, `REZS_FOND` type) but values come back empty and `requestedFacets` 500s. The CSV/XLS export (`/export?target=…&object=…`, capped at 400 records) returns **HTTP 504** even with a session cookie — treat as unavailable.
```
curl -sL -A "Mozilla/5.0" --get --data-urlencode "q=<term>" \
  --data-urlencode "pageSize=100" --data-urlencode "pageNumber=<n>" \
  --data-urlencode "sorting=-REZS_ROK" "https://katalog.mekvalmez.cz/api/search"
```

**Discovery sweep — use the catalogue to *find* candidates, not only to confirm them** (added 2026-08-26). Name-first searching only ever confirms books already thought of, so it inherits the blind spots of the Author table. Two axes that actually yield:
- **Publisher-scoped, because Czech imprints sort themselves by audience.** Adult/translated SF-F: *Triton* / *Planeta9*, *Laser-books*, *Argo*, *Baronet*, *Návrat*, *Polaris*, *Host*. Skip for this reader: *Fragment*, *CooBoo*, *Dobrovský*, *Mystery Press*, *Slovart* romantasy (crude-sexual-content risk is central, not incidental) and *Crew* (manga, wrong format).
- **Theme keywords tied to the profile, not the genre** — `první kontakt`, `kolonizace vesmíru`, `utopie`, `totalitní`, `svědectví`. Genre terms plus `-REZS_ROK` mostly return the current YA/romantasy intake; sort `REZS_ROK` or scope by publisher to reach the canon instead.
